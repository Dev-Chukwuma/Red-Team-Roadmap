# 🔴 30 Days of Red Team Cybersecurity

> **"Learn to think like an attacker, so i can defend like a pro."**

A hands-on journey into Red Teaming, penetration testing, offensive security, and adversary simulation.

The goal is simple:

**Learn → Practice → Document → Improve.**

This journey contains 30 practical modules, covering everything from reconnaissance and enumeration to exploitation, privilege escalation, Active Directory, and full Red Team simulations.

## 🗺️ Roadmap

### 🔎 Phase 1 — Reconnaissance

**01 — Red Team Fundamentals**
Understand Red Teaming, the attack lifecycle, Rules of Engagement, and the difference between Red, Blue, and Purple Teams.

**02 — Attack Surface & Threat Modeling**
Learn how attackers identify systems, users, applications, infrastructure, and potential entry points.

**03 — OSINT Fundamentals**
Learn how publicly available information can contribute to an attack.

**04 — Passive Reconnaissance**
Learn WHOIS, DNS, certificate transparency, search techniques, and other passive reconnaissance methods.

**05 — Network Reconnaissance**
Learn host discovery, port scanning, TCP/UDP concepts, and Nmap.

**06 — Service Enumeration**
Learn how to investigate services such as HTTP, SSH, FTP, SMB, and DNS.

**07 — Reconnaissance Project**
Combine the reconnaissance skills learned so far into a complete controlled reconnaissance assessment.

---

### ⚔️ Phase 2 — Exploitation

**08 — Vulnerability Assessment**
Learn vulnerabilities, CVEs, CVSS, vulnerability scanning, and risk assessment.

**09 — Exploitation Fundamentals**
Understand vulnerabilities, exploits, payloads, and initial access.

**10 — Metasploit Fundamentals**
Learn the Metasploit Framework and how exploitation workflows operate in controlled labs.

**11 — Password & Hash Security**
Learn password hashing, hash identification, password attacks, and cracking concepts.

**12 — Web Enumeration**
Learn how to discover directories, files, endpoints, technologies, and web services.

**13 — Web Vulnerabilities**
Study SQL Injection, XSS, IDOR, authentication weaknesses, and access-control issues.

**14 — Web Security Project**
Perform a controlled web application security assessment and document the findings.

---

### 🐧 Phase 3 — Post-Exploitation

**15 — Linux Privilege Escalation**
Learn how Linux permissions and misconfigurations can lead to privilege escalation.

**16 — Windows Privilege Escalation**
Study Windows services, permissions, scheduled tasks, tokens, and common misconfigurations.

**17 — Credential Discovery**
Understand where credentials and sensitive information may be exposed.

**18 — Shells & Payload Concepts**
Learn the concepts behind shells, payloads, and remote command execution in controlled labs.

**19 — Post-Exploitation**
Learn how attackers enumerate and understand a system after gaining access.

**20 — Lateral Movement**
Understand how attackers move between systems inside an internal environment.

**21 — Privilege Escalation Project**
Complete a controlled attack path from initial access to higher privileges.

---

### 🏢 Phase 4 — Active Directory

**22 — Active Directory Fundamentals**
Learn domains, Domain Controllers, users, groups, computers, GPOs, and organizational units.

**23 — Active Directory Enumeration**
Learn how to discover users, groups, computers, permissions, relationships, and trusts.

**24 — Kerberos Fundamentals**
Understand Kerberos authentication, tickets, TGTs, service tickets, and authentication flow.

**25 — Credential Attacks in AD Labs**
Study controlled scenarios involving weak credentials, password spraying, and credential exposure.

**26 — BloodHound & Attack Paths**
Learn how BloodHound can visualize relationships and identify potential attack paths.

**27 — Active Directory Lateral Movement**
Study how attackers can move between systems within an AD environment.

**28 — Domain Privilege Escalation**
Learn how excessive privileges and misconfigurations can create paths toward highly privileged accounts.
